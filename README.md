# Dengue Statistics in Matara District

### Numerical Analysis | MATLAB Programming | Mathematical Interpolation

## Project Overview

This project applies numerical analysis techniques to examine dengue case data in Matara District, Sri Lanka.

The study implements different interpolation methods to approximate dengue case values, estimate missing data points, and compare the performance of various mathematical interpolation techniques using MATLAB.

## Project Objectives

- Apply numerical interpolation techniques to dengue case data.
- Construct polynomial approximations using different interpolation methods.
- Estimate missing values using interpolation.
- Compare different interpolation curves and approximation methods.
- Visualize the results using MATLAB.

## Numerical Methods

The project covers the following techniques:

**1. Cubic Spline Interpolation**
- Construct piecewise cubic spline polynomials.
- Generate smooth interpolation curves.
- Estimate intermediate values.

**2. Newton's Divided Difference Interpolation**
- Construct interpolation polynomials using divided differences.
- Approximate values between observed data points.

**3. Lagrange Interpolation**
- Develop Lagrange interpolation polynomials.
- Estimate missing data values.
- Visualize polynomial approximations.

**4. Least Squares Approximation**
- Fit an approximate mathematical relationship to the data.
- Compare the fitted curve with actual observations.

## Results and Visualization

The project compares different interpolation techniques through MATLAB-generated graphs, illustrating how each method approximates the observed dengue case data.

The analysis also demonstrates the use of Lagrange interpolation for estimating missing values and cubic splines for constructing smooth curves.
